Download program for the files (VPN split tunnelling)
DMM refuses its download links from VPN addresses, but its file servers don't (and can be much faster through a VPN). With DMM-Fetch.exe, only the files themselves are downloaded by that separate program. In your VPN's split tunnelling, let only that program use the VPN (or keep DMM-Downloader off it): logging in, your library and the download links keep using your normal connection.
Japan route for the VR Channel (DMM gives the VR Channel's downloads only in Japan)
Two ways: connect your VPN app to a server in Japan (the whole computer, or with DMM-Downloader in its split tunnelling) and leave this empty; or enter a proxy in Japan, e.g. wireproxy with a WireGuard config from a VPN with servers in Japan (see the README), so nothing else changes. Only the VR Channel's qualities, its download list and its download links use this route, as a normal Windows browser. The files themselves use your normal connection (or DMM-Fetch), and the proxy only when DMM's file server refuses them. Logging in, your library and Premium never use the proxy. “Check” asks DMM whether the route counts as Japan.
